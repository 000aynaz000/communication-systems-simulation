# Communication Systems Modeling and Simulation

A collection of MATLAB-based projects completed for the Communication Systems course at Sharif University of Technology.

The projects explore signal processing, analog and digital communication techniques, channel modeling, and communication system performance evaluation.

## Project 1 – Signal Processing

- Autocorrelation and cross-correlation analysis
- System identification and channel modeling
- Audio denoising using notch and low-pass filters
- Channel equalization
- Sampling theorem and aliasing
- DTMF signal detection and decoding

## Project 2 – Analog Communication Systems

- AM, DSB-SC, and SSB modulation and demodulation
- Frequency and phase modulation (FM and PM)
- Direct and indirect FM generation
- AWGN channel modeling and SNR analysis
- Frequency Division Multiplexing (FDM)

## Project 3 – Digital Communication Systems

- Digital baseband signal transmission
- BPSK, QPSK, and 16-QAM modulation
- Matched filtering and optimal sampling
- Bit Error Rate (BER) analysis
- Eye diagram and constellation analysis

## Tools and Technologies

- MATLAB
- Signal Processing
- Digital and Analog Communications
- Fourier Analysis
- Statistical Performance Analysis

## How to Run

Open the corresponding project folder in MATLAB, set it as the current working directory, and execute the desired MATLAB script.

Some experiments require MATLAB toolboxes, input audio files, or microphone access. Where original input data cannot be distributed, suitable replacement data must be provided.

## Documentation

Each project includes MATLAB implementations and accompanying reports describing the theoretical background, simulation methodology, and results.
